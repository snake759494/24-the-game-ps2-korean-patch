# 기술 메모

- 디스크: GAMEDATA 묶음 파일 안에 그룹(`*.group.toc`)별 항목이 있고, 텍스트는 `LTR`(LANG/LNG1 청크, SCSU 인코딩)입니다. 영어·프랑스어·스페인어 LTR이 연속 영역에 있어, 한국어 파일을 그 자리에 쓰고(모자라면 디스크 끝에 추가) 세 언어 항목이 모두 가리키게 합니다.
- 글꼴: `movies_1` 그룹 E2335~2339의 FBM1(PSM0 4bpp 32×32 글리프). fid0·1은 본문(전체 한글), fid2는 메뉴(짧은 문구·제목 글자), fid3·4는 짧은 제목용.
- 메모리: 글꼴이 레벨 힙에 올라가므로 글리프 수가 많으면 갑판 계단(선박 구역 로딩)에서 큰 할당이 실패해 멈춥니다(memcpy 대상 0). 글꼴 세트를 용도별로 나누고, 쓰이지 않는 악센트 글리프를 제거해 해결했습니다. 실행 파일(ELF)은 수정하지 않습니다.
- 확인 도구: `tools/emu.py`(PCSX2 PINE 메모리 접근·상태 저장), `tools/heap.py`(EE 힙 체인 분석).
